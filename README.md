Crime Investigation SQL Project

Project Overview

This project uses SQL and PostgreSQL to manage and analyze crime investigation data.

Database Tables

1. Officers
2. Suspects
3. Locations
4. Crime Scenes
5. Evidence
6. Witnesses

Project Objectives

- Store crime investigation data.
- Manage officers and suspects.
- Track crime scenes and locations.
- Record evidence and witness statements.
- Analyze crime-related information using SQL queries.

SQL Concepts Used

- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- DISTINCT
- JOIN
- GROUP BY
- HAVING
- Aggregate Functions
- Common Table Expressions (CTE)
- Window Functions (RANK)

Tools Used

- PostgreSQL
- pgAdmin 4
- GitHub
